# Security Policy

## Reporting a vulnerability

Please report security problems privately, not as a public issue. Go to the Security tab of this repository and choose "Report a vulnerability":
https://github.com/lazyb5/GVoicePlus/security/advisories/new

Include what you found, how to reproduce it, and your app version and operating system. This is a hobby project run by one person, so I can't promise a response time, but I will do my best to answer.

## Supported versions

Only the latest release gets fixes.

## Google Voice itself

For problems with Google Voice (the website), see the Google Voice community:
https://support.google.com/voice/community
